This repository contains some simple tools vaguely or directly related to AIOLOS (Schulik&Booth2023).
The plotting tool makes a user familiar with the column structures of AIOLOS outputs, without having the need to study them in detail.
The numerical chemistry tool is an educational way to approach code development, based on how the AIOLOS chemistry solver was built, which itself is based on VULCAN (Tsai+2017). 
Climate change on Exoplanets is a way to connect research level opacity data (using the Exo-k tool, Leconte+2021) with extremely simple calculations of planetary surface temperatures, which can be understood by highschool or undergrad stuents.
